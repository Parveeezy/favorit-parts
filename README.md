# Favorit Parts Search

Веб-приложение для поиска автозапчастей и их аналогов через прайс-API Favorit Parts.

**Демо:** _ссылка_

## Возможности

1. **Поиск производителей.** Введите номер детали, и поиск запустится сам через 500 мс после окончания ввода (или сразу по Enter и кнопке «Найти»). Появится список производителей, у которых есть деталь с таким номером.

2. **Предложения и аналоги.** По клику на производителя загружаются сама деталь и все её аналоги. Одна строка соответствует одной детали: минимальная цена, суммарный остаток и число складов. Клик по строке раскрывает склады с ценой, остатком, датой отгрузки и отметкой «невозвратный». Исходная деталь всегда идёт первой и помечена как «Оригинал», аналоги отсортированы по наличию и цене. Аналогов бывают сотни, поэтому они подгружаются порциями по 100.

Приложение обрабатывает пустые результаты, ошибки API, сетевые сбои и некорректные ответы, а для повторной попытки есть кнопка «Повторить». Устаревшие ответы отбрасываются, поэтому медленный старый запрос не перезапишет результат нового.

## Стек

React, Vite, Redux Toolkit, Bootstrap 5, Vitest, ESLint.

## Запуск

```bash
cp .env.example .env
npm i
npm run dev
```

В `.env.example` указан демо-ключ. Чтобы использовать свой, замените значение `FAVORIT_API_KEY` в `.env`.

```bash
npm test        # тесты
npm run lint    # линтер
npm run build   # сборка
```

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel (Add New, Project).
2. Framework Preset определится автоматически как Vite.
3. В Environment Variables добавьте `FAVORIT_API_KEY`.
4. Нажмите Deploy.

## Прокси-функция

Браузер обращается не к API Favorit, а к `/api/price` (файл `api/price.js`). На это три причины. API работает по http, а сайт по https, и браузер заблокировал бы такой запрос. У API нет CORS-заголовков. А ключ клиента должен оставаться на сервере и не попадать в бандл.

Функция подставляет ключ из переменной окружения, ограничивает время ожидания 10 секундами и при недоступности API возвращает 502 с описанием ошибки. Локально тот же обработчик подключён к dev-серверу Vite, поэтому хватает обычного `npm run dev`.

## Цены

Поле `price` у товара в API устарело, актуальная цена своя у каждого склада. Поэтому в строке детали показывается минимальная цена по складам, а в раскрытой строке цена каждого склада отдельно.
